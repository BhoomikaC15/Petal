# 🌸 Petal

A cute and minimalist expense tracker designed to make budgeting feel simple and enjoyable.

Petal helps users set a monthly budget, record daily expenses, and track spending throughout the month. All data is stored locally in the browser, keeping personal financial information private and accessible only on the device being used.

## ✨ About This Project

This project was created for the **MLH Global Hack Week Builders Week** challenge:

**Challenge 1: Build a Mini App with Cursor**

The application was built entirely using **Cursor** and its **Groq-powered AI model**.

My role was to define the product vision and requirements, including:

- Theme and concept
- Features and functionality
- User experience goals
- Visual style and aesthetic
- Custom color palette (hex color selection)

I specified that the project should be a cute, sweet, and easy-to-use expense tracker, and the implementation was generated through AI-assisted development using Cursor and Groq.

## 🌷 Features

- Set a monthly spending budget
- Record expenses quickly
- Track daily spending throughout the month
- Clean and beginner-friendly interface
- Cute pastel-inspired design
- Local browser storage
- No sign-up or account required
- Works entirely in the browser

## 🎨 Design Philosophy

Petal was designed to make personal finance feel less intimidating and more approachable. The interface embraces a soft, floral-inspired aesthetic while keeping budgeting simple and practical.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Set your monthly budget.
4. Start recording expenses.

No installation, backend, or additional setup is required.

## 💾 Data Storage

Petal uses browser local storage to save:

- Monthly budget
- Expense records

All data remains on the user's device and is not transmitted anywhere.
