# Petal

This is a project created on the first day of Global Hack Week. It is Challenge 1.

## Challenge 1: Build a Mini App with Cursor

Build a small working app from scratch with Cursor scaffolding and debugging alongside you.

Petal is a small expense tracker. You set a monthly budget, record spends, and see the money spent each day of the month. Open `index.html` in a browser to use it. Your budget and spends stay in that browser.
